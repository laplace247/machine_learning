# Predicción de Rotación de Empleados (Employee Churn)

## Objetivo
Predecir si un empleado tiene alta probabilidad de dejar la empresa usando un modelo de red neuronal.

## Dataset
IBM HR Employee Attrition Dataset.

## Variables utilizadas
- Edad
- Ingreso mensual
- Cargo
- Años totales trabajados
- Años en la empresa
- ¿Hace horas extra?
- ¿Viaja por trabajo?

## Entrenamiento del modelo
- Herramientas: Python, TensorFlow, Keras
- Red neuronal: 2 capas ocultas con ReLU, salida con Sigmoid
- Optimización: Adam
- Métrica: Accuracy

## Uso web
Formulario en HTML + JS con TensorFlow.js
Carga del modelo en el navegador y predicción en tiempo real.

## Conclusión
Una herramienta gerencial útil para anticipar rotación de personal.
